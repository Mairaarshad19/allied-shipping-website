# Allied Shipping Agency Website

A modern, responsive website developed for **Allied Shipping Agency**, a Pakistan-based freight forwarding and cargo booking company with over **25 years of industry experience**.

The website presents the company's logistics services, business information, export markets, and contact details while providing a professional online presence optimized for performance, SEO, and user experience.

## Live Demo

🌐 https://allied-shipping-agency.vercel.app/

## Features

- Modern and responsive UI
- Professional hero section
- Sea Freight, Air Freight & Cargo Booking services
- Export markets and trade lanes
- Company overview with mission and vision
- Contact section with interactive Google Maps
- Click-to-call, WhatsApp and email integration
- SEO optimized metadata
- Open Graph & Twitter preview support
- Local Business structured data (JSON-LD)
- Mobile-friendly navigation
- Smooth scrolling navigation
- Optimized images and performance
- Clean and accessible design

## Installation

Clone the repository

```bash
git clone https://github.com/Mairaarshad19/allied-shipping-website.git
```

Navigate into the project

```bash
cd allied-shipping-website
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

## Deployment

The project is deployed using **Vercel**.

To deploy your own version:

```bash
npm run build
```

or connect the repository directly with Vercel for automatic deployments.
